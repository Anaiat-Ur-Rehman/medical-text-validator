# Medical Text Validator & Evaluator

A lightweight Python utility designed to screen clinical text records, validate medical keywords, and support safety constraint checks for AI dataset annotation and model evaluation.

## Features
- Screens text for critical clinical and emergency indicators.
- Automates tag extraction for health-domain dataset curation.
- Structured code framework tailored for remote AI domain expert tasks.

## Tech Stack
- Python
- Regular Expressions (Regex)
